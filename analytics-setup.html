첫 번째 스윙.

Mixpanel과 Google Tag Manager 연결을 준비하세요. 토큰을 입력하면 Fairway 택소노미에 맞는 태그와 설치 코드를 생성합니다.

택소노미 v1.0 · 설정 생성 도구
이 페이지는 공개된 정적 설정 도구입니다. 입력만으로 사이트 설정이 바뀌거나 GTM에 게시되지 않습니다. Google OAuth 토큰은 접근 확인에만 사용하며 저장·다운로드하지 않습니다. 이 페이지 자체에는 분석 태그가 없습니다.
01 / MIXPANEL

데이터가 도착할 곳

Project Settings → Access Keys에서 Project Token을 확인하세요.

Project Token만 입력하세요. API Secret·서비스 계정 비밀번호는 받지 않습니다.
Mixpanel 프로젝트의 실제 리전과 일치해야 합니다. 개발·운영에는 별도 프로젝트 토큰 사용을 권장합니다.
02 / GOOGLE TAG MANAGER

웹 컨테이너 연결

웹사이트 설치 코드의 GTM-으로 시작하는 ID입니다.
API 접근 확인 (선택)

GTM API를 사용하려면 API Key가 아닌 Google OAuth 2.0 액세스 토큰이 필요합니다. Google Cloud에서 Tag Manager API를 활성화하고, 해당 계정에 접근 가능한 사용자 토큰을 사용하세요.

숫자로 된 내부 ID입니다. 위의 GTM-XXXXXXX와 다릅니다.필요 범위: https://www.googleapis.com/auth/tagmanager.readonly
Client Secret, Refresh Token, 서비스 계정 JSON은 입력하지 마세요.

접근 확인을 누르면 인증 토큰을 HTTPS Authorization 헤더로 Google Tag Manager API에만 전송합니다. 태그 생성·수정·게시 권한은 사용하지 않습니다.
03 / GENERATE

태그 준비하기

저장 버튼은 Mixpanel 공개 토큰·컨테이너 ID·리전 등만 이 브라우저에 저장합니다. OAuth 인증 토큰은 항상 제외됩니다.

GTM에 붙여 넣을 코드

생성 완료는 수집 활성화를 뜻하지 않습니다. 아래 순서에 따라 설치·미리보기·게시를 완료하세요. Mixpanel 토큰의 유효성은 실제 이벤트 수신으로 확인합니다.

1. GTM Custom HTML 태그

2. 사이트 <head>에 설치할 GTM 코드

3. <body> 바로 다음에 설치할 코드

설정 JSON은 검토·전달용이며 GTM 컨테이너 가져오기 파일이 아닙니다. 다운로드에 Google 인증 토큰은 포함되지 않습니다.

게시까지 네 단계

  1. Mixpanel 토큰과 GTM 공개 ID를 입력하고 코드를 생성합니다.
  2. GTM에서 Custom HTML 태그를 만들고 생성 코드를 붙여 넣습니다. 기본 실행 시점은 DOM Ready이며 수집 동의 조건을 함께 적용합니다. 태그 발화 옵션은 Once per page로 설정합니다.
  3. Fairway의 index.html에 head·body 설치 코드를 각각 한 번 추가하고 GitHub에 커밋합니다. 설정 페이지에는 설치하지 않습니다.
  4. GTM Preview에서 동작을 검증하고 Mixpanel에서 이벤트 수신을 확인한 뒤 GTM에서 Submit / Publish 합니다.
