# Fairway — Find your swing

A simple, responsive golf swing learning website built with HTML, CSS, and JavaScript.

- Six YouTube lessons arranged in swing order
- Category filters for setup, backswing, downswing, and finish
- Original SVG golf course illustration
- Practice checklist saved in the browser

## Preview
Open `index.html` in a browser. No build or installation is required.
Internet access is needed for Google Fonts, YouTube thumbnails, and videos.

## GitHub Pages
In Settings → Pages, choose **Deploy from a branch**, then **main** and **/ (root)**.
